# iSawIt
Static PWA (index.html, app.js, sw.js, manifest.json) for logging BCI (Panama) sightings.
- `config.json` is GENERATED by `build_config.py` from the `*.csv` files. Never read or hand-edit it (60+ KB); edit the script and rerun.
- Insects Quick list = 50 species (test); all ~1,940 are in `taxaFull`.
- Scientific names only for now; common names are in the CSVs for later.
- Bump `CACHE` in sw.js when data/code changes.
